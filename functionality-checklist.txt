Admin Dashboard - for the Admin:
The admin should be added, whenever a new database is created (done)
The admin creates/edits/deletes a subject (done)
The admin creates/edits/deletes a chapter under the subject (done)
The admin will create a new quiz under a chapter (done)
Each quiz contains a set of questions (MCQ - only one option correct) (done)
The admin can search the users/subjects/quizzes  
Shows the summary charts

Quiz management - for the Admin:
Edit/delete a quiz (done)
The admin specifies the date and duration(HH: MM) of the quiz (done)
The admin creates/edits/deletes the MCQ (only one option correct) questions inside the specific quiz (done, to confirm)


User dashboard - for the User:
The user can attempt any quiz of his/her interest
Every quiz has a timer (timer is optional)
Each quiz score is recorded
The earlier quiz attempts are shown
Shows the summary charts
